# Part 1 Opportunity Map

## Confirmed Target Opportunity
**Record ID:** `fd8a8056`

**1. User problem:** The user cannot find previously uploaded old photos that hold high sentimental value, leading them to believe the app deleted the images automatically, causing a severe loss of trust.
**2. Retrieval intent:** Finding old pictures that were uploaded a long time ago.
**3. What the user remembers:** The user remembers the photos exist, that they represent "pretty good memories," that they uploaded them a long time ago, and that they did not delete them.
**4. What the user does not know / cannot locate:** The current location of these specific photos within the app.
**5. Search strategy:** UNKNOWN
**6. Outcome:** Complete failure to find the pictures; the user concluded that "images are removed on its own" and they "can't trust Google any more."
**7. Evidence quote:** "while trying to find some old pics which already uploaded a long time ago, I can't find them now"
**8. Evidence vs hypothesis:**
- *Evidence:* The user looked for old photos, couldn't find them, and blamed the application for deleting them automatically.
- *Hypothesis:* The photos might still be in the library but are difficult for the user to locate among their content, or the user is looking in the wrong account.
**9. Retrieval category:** Episodic memory / Re-finding known items.
**10. Underlying user need:** To reliably access and periodically view cherished old memories.
**11. Memory-to-search gap:** The user remembers the sentimental value and the fact that they are "old," but lacks specific details to construct a successful retrieval query.
**12. Product opportunity hypothesis:** Providing tools that help users verify the existence of items they believe are missing, or improving ways to resurface older episodic memories without requiring specific search terms, could help prevent this specific breakdown in trust.
